# CEO workflow (restored 2026-11-14 after container reset)

Applies when the work has 2 or more independent tasks. A single task skips the Analyzer and is done directly.

1. CEO: writes the goal and a draft task list.
2. Analyzer: reviews the draft, finds gaps, overlaps and risks.
3. CEO: finalises the list.
4. Analyzer: assigns one model per task and writes each brief.
5. Models: run the tasks in parallel. CEO merges results, applies fixes, verifies.

## Model per task
| Kind of task | Model |
|---|---|
| Mechanical (rename, move, bulk replace, link lists) | Haiku |
| Build and test (code, browser checks, link checks) | Sonnet |
| Writing and design (copy, critique, UX) | Opus |
| CEO / hard cross-cutting decisions | Fable, only with Firas's approval |

## Standing rules
- No invented clients, testimonials or numbers. No Hakeem / MOH / EHS names.
- /layan/ (Arabic page) stays untouched.
- Save work off the container at the end of every phase (commit + push, or send a zip). Nothing goes to the live site without Firas's approval.
