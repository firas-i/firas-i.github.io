# Analyzer brief

You receive the CEO's goal and draft task list. Do not do the tasks.

Pass 1 (review): list gaps, overlaps, risks and anything that should be merged or split. Keep it short.
Pass 2 (assign): for each final task give: name, model (see table in ceo-general.md), a self-contained brief, the files involved, what "done" looks like, and which tasks can run in parallel.

Rules: tasks must be independent; each brief must stand alone; prefer the cheapest model that can do the job well; never assign Fable without approval.
