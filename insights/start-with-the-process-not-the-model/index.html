Start with the process, not the model

A practical order of work for automation projects, and the questions to settle before anyone opens an AI tool.

All In·6 November 2026·4 min read

The usual way an automation project starts is with a tool. Someone sees a demo, the tool is impressive, and the question becomes "where can we use this?" It is the wrong question, and it produces pilots that impress in a meeting and are quietly switched off three months later.

The better order is the boring one. Start with the process.

1. Find the work that is late or dropped

Do not begin with the work your team does well. Begin with the work that is not getting done: the calls that ring out after closing, the enquiries answered two days late, the follow-ups nobody has time to send. Automating these adds capacity without threatening anyone's job, which matters more for adoption than any technical choice.

2. Write down what "done" means

For each candidate task, describe the finished result in one sentence a new employee would understand. "A request appears in the reception queue with the patient's name, number, what they want and when." If you cannot write that sentence, the task is not ready to automate. It needs analysis first.

3. Decide where the person stays in the loop

Almost no process should be automated end to end on day one. Decide which step keeps a human decision, and design the hand-over so that the person receives everything they need in one place. A good hand-over is the difference between an assistant staff rely on and one they work around.

4. Only now, choose the technology

With the task, the definition of done and the hand-over fixed, the technology choice is usually straightforward, and sometimes it is not AI at all. A form and a reminder rule solve more problems than people expect. When a language model is the right tool, you now know exactly what to ask of it and how to test whether it delivers.

5. Measure the thing you set out to fix

Pick one measure tied to the original problem, such as how many after-hours enquiries received a reply, and look at it weekly for the first two months. Resist dashboards with twenty charts. One number that the business owner cares about keeps the project honest.

What this looks like in practice

None of this is sophisticated. It is simply the order in which the questions have to be answered, and skipping ahead to step four does not make steps one to three go away. It only means you answer them later, under pressure, with a tool already purchased.
